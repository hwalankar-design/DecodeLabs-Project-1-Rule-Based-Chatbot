# Rule-Based AI Chatbot

## DecodeLabs Artificial Intelligence Internship — Project 1

### About the Project
Nova is a simple rule-based chatbot built using Python. It responds to predefined user inputs using conditional statements and continues the conversation until the user enters an exit command.

### Features
- Responds to greetings and basic questions
- Provides predefined responses about AI and Python
- Handles different input formats
- Maintains a continuous conversation loop
- Supports exit commands
- Provides a default response for unrecognized inputs

### Technologies Used
- Python 3
- `if`, `elif`, and `else` statements
- `while` loop
- String handling and conditional logic

### How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python chatbot.py
```

5. Type a message to chat with Nova.
6. Enter an exit command to end the conversation.

### Learning Outcomes
This project helped me practise Python fundamentals, conditional statements, loops, and basic rule-based chatbot development.
